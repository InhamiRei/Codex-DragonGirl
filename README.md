## 她能做什么

- **桌面陪伴**：透明背景、鼠标穿透、拖动吸附、缩放、翻转、自定义角色图片与轻点互动。
- **角色切换**：首次安装默认龙娘。点击龙娘发饰，或通过右键 / 托盘「切换角色」、偏好设置的「内置角色」选择龙娘或麻吕；升级保留已选角色。
- **麻吕互动**：待机睁眼、无口，双颊带红晕，会自然眨眼并小幅看向鼠标；轻点和任务完成时闭眼，失败时显示创可贴表情。待机偶尔播放约五秒的慢速捋发，低头、单眼偷瞄后缓缓恢复；30 帧使用 1254×1254 透明原图，配色、尺寸和身体位置统一。工作时可通过「表情 → 捋头发」手动播放。
- **自动朝向**：拖到左半边松手后默认用约 0.3 秒平滑镜像，右半边松手后恢复。跟随模式按宿主窗口左右判断，独立桌面按所在屏幕判断；可在「偏好设置 → 外观 → 自动朝向」关闭，并保留手动翻转。关闭动画反馈或系统减少动态效果时直接切换。
- **视线与眨眼**：龙娘和麻吕的眼睛跟随全屏鼠标，龙娘的身体稍慢地轻微配合；静止时也会不定时轻眨双眼，快速闭合、稍慢睁开。「偏好设置 → 外观」中的「眼睛跟随」与「自然眨眼」可分别开关，「动画反馈」可关闭身体配合。隐藏、拖动时暂停眨眼；自定义图片保持原样，系统减少动态效果时暂停联动。
- **开心星光**：轻点默认角色或主任务完成时，紫色虹膜内的星芒和柔光会缓慢漂移、明暗变化，配合一次轻弹，约两秒后恢复。保留原来的无口造型；拖动、取消和错误任务不会触发，静音时仍可显示，可在「偏好设置 → 外观 → 动态表情」关闭。
- **伤心含泪**：主任务失败时，眼皮轻垂、泪光流动，一小滴泪珠缓缓滑落，约六秒后恢复。继续保持无口造型；取消任务、子任务失败及额度查询异常不会触发伤心。
- **表情预览**：右键角色或打开托盘菜单，龙娘可选择「表情 → 开心 / 伤心」，麻吕可选择「完成 / 失败 / 捋头发」，结束后自动恢复。表情预览需开启「动态表情」，捋发还需开启「动画反馈」。
- **窗口跟随**：跟随当前 Codex 窗口的位置与前后层级，多开时可设置每个运行实例一只；被其他窗口遮挡时，角色和气泡一起被遮挡，最小化后自动隐藏。macOS 打开文件或文件夹选择框时暂时收起角色与气泡，关闭后恢复原位置。独立桌面模式保持置顶。
- **启动联动**：首次开启「随 Codex 启动」后，照常打开 Codex，龙娘就会自动出现；自动启动不弹管理窗口。
- **额度气泡**：用横向十格电量条查看实际剩余额度，每个窗口同时显示重置时间，跨日使用 `11.12` 形式的月日与时分；底部今日 Tokens 以同字号细字整行居中，数字用稍深的紫色区分，普通双额度无需滚动。周额度耗尽时，同一额度桶的 5 小时可用量也显示 0%，电量条清空；周额度恢复后恢复真实 5 小时读数，气泡和总览保持一致。Pro 仅返回周额度时补一条标注「无限制」的 5 小时展示行，电量和百分比跟随周额度，悬停可查看说明。真实计量窗口不变，时间沿用统计时区，缺失时间明确标注未知。后台更新原位显示，不重复播放淡入；长内容保留阅读位置。
- **气泡语录**：轻点龙娘查看用量，再点气泡显示一条日常语录，再点气泡收起；50 条日常文案逐轮切换，另有 10 条任务提示。点击龙娘也可收起，右键菜单「说句话」可直接互动。
- **多实例总览**：自动发现默认目录、Cockpit 多开目录，也可手动添加；同一账户的共享额度会作提示。
- **本机账本**：按日期、实例、模型、来源筛选，查看模型分布、年度活动热力图和会话明细，支持 CSV / JSON 导出。
- **账号测智**：从账户总览选择实例，用鹈鹕动画或自定义提示词对比回答；支持共同模型与思考强度、并发、取消、动画预览和本地测试记录。
- **提醒与声音**：任务完成、异常、低额度和预算提醒；支持原声音效、事件音量、免打扰时段及自定义气泡。
- **本地保存**：设置与统计保存在本机，支持设置导入导出、账本备份和重建。

## 下载与安装

前往 [Releases](https://github.com/InhamiRei/Codex-DragonGirl/releases/latest)，展开 **Assets**，按电脑系统选择文件。运行发行包不需要 Node.js、npm 或工程源码。

| 电脑 | 下载文件 | 打开方法 |
| --- | --- | --- |
| Windows 10 / 11，Intel / AMD 64 位 | `Codex-DragonGirl-1.5.0-Windows-x64.zip` | 完整解压后双击文件夹内的 `DragonGirl.exe` |
| macOS 15+，Apple Silicon | `Codex-DragonGirl-1.5.0-macOS-arm64.dmg` | 把「Codex 龙娘.app」拖入 Applications |
| 同上，偏好 ZIP | `Codex-DragonGirl-1.5.0-macOS-arm64.zip` | 解压后打开 App，或移入 Applications |

Windows 请保留解压后的整个文件夹，程序需要旁边的运行时文件。当前暂未提供 Windows ARM 原生版和 Intel Mac 版。

安装包未作商业代码签名；macOS 包采用 ad-hoc 签名，尚未进行 Apple Developer ID 公证。首次打开可能需要系统确认，请从本仓库 Release 下载并核对附件中的 SHA-256。macOS 若拦截，可在「系统设置 → 隐私与安全性」中允许本应用。

## 第一次使用

1. **先安装并登录 Codex。** 龙娘读取本机已有实例，无需在龙娘里填写密码或 API Key。Windows 如未找到内置 CLI，可安装官方 Codex CLI 后重启龙娘。
2. **打开龙娘。** 管理窗口自动显示发现的账户与目录。首次建立历史账本可能需要几分钟，额度查询独立进行。
3. **选择摆放方式。** 在「偏好设置 → 外观」选择跟随窗口或独立桌面；右键角色可恢复位置、调整大小或进入管理界面。
4. **轻点试听。** 九段原声音效已随应用附带，首次打开即可离线播放，无需下载。可在「偏好设置 → 声音」调整音量或修复音效。
5. **查看用量与互动。** 轻点龙娘打开用量气泡，再点气泡显示一条语录，再点气泡收起；点龙娘也可收起。点击托盘 / 菜单栏图标打开账户总览、用量账本和偏好设置。

显示 / 隐藏主龙娘的快捷键：macOS 为 `⌘⌥⇧D`，Windows 为 `Ctrl+Alt+Shift+D`。也可使用右键菜单操作。

### 随 Codex 自动启动

打开「偏好设置 → 外观 → 启动方式」，选择 **随 Codex 启动** 并保存一次。之后继续使用原来的 Codex 图标即可，无需另开龙娘。首次默认保持手动启动，升级保留原来的选择。

| 启动方式 | 行为 |
| --- | --- |
| 手动启动 | 需要时打开龙娘，同时显示管理窗口。 |
| 登录电脑时启动 | 登录后静默打开龙娘，从托盘或菜单栏进入管理界面。 |
| 随 Codex 启动 | 登录后由小型后台助手等待 Codex，发现桌面应用后启动龙娘；在跟随模式下，全部 Codex / ChatGPT 宿主退出后，自动启动的龙娘保存并退出。 |

最小化只隐藏角色，恢复窗口后继续跟随。点击「退出龙娘」后，本批 Codex 实例全部结束前不会自动重开；手动再次打开龙娘可以立即恢复。手动启动、手动打开管理界面或使用独立桌面模式时，可以继续使用账本与桌面陪伴，退出由用户控制。

Windows 和 macOS 的助手均随安装包附带，无需安装 Node.js。关闭联动时，选择「手动启动」并保存，会移除本应用的登录项。更新或移动安装目录后，手动打开新版一次即可更新路径；macOS 请先移入 Applications，Windows 请保留完整解压目录。卸载前先切回手动启动。

若设置提示助手未连接，可先保存为手动启动，再重新开启联动；同时检查系统的登录项 / 启动应用是否允许龙娘运行。注册失败会显示错误并保留原来的设置。

Windows 跟随针对同一系统用户运行的 Codex / ChatGPT 桌面窗口。受系统权限保护或以其他用户运行的进程可能无法识别，可切换独立桌面模式，并手动添加目录。WSL 内部的独立账户和 Linux 窗口暂不作自动映射。

### 统计口径

- **账户额度**来自各实例的官方账户接口，保留实际返回的计量桶、窗口长度、重置时间和重置卡。未知、断网、过期与真实零值分别显示。
- **本机用量**来自 `sessions/`、`archived_sessions/` 的本地日志及 Zstandard 归档；支持请求记录和旧格式累计差分，缓存与推理分项不重复计入总量。
- **参考费用**是接口等价估算，不能替代订阅账单。未知模型和未经核对的历史价格保持未定价，可在设置中补充价格。
- **任务提醒**依据日志中的真实事件触发，不推测未观测到的等待和授权状态。
- 手动刷新等待账户查询和增量索引结束后显示结果；共享账户的多个目录不能作为多份独立额度相加。

### 用户数据目录

| 系统 | 位置 |
| --- | --- |
| Windows | `%APPDATA%\Codex DragonGirl\` |
| macOS | `~/Library/Application Support/Codex DragonGirl/` |

目录包含 `preferences.json`、`settings.json`、`usage.sqlite`、最近额度快照和本机角色 / 音效文件。索引只保存统计字段，不保存对话正文、回答或工具输出；发行包不包含作者的账户、会话和数据库。

龙娘不会修改原始会话日志。官方 CLI 自身可能按其正常规则刷新登录缓存。删除龙娘用户数据目录会清除龙娘的设置和账本；升级时保留此目录即可。

## 开发与构建

需要 Node.js 24+。Windows 构建使用系统内置 .NET Framework 编译器；macOS 原生桥需要 Xcode Command Line Tools。

```sh
npm ci
npm run build:native
npm start
```

```sh
# 通用检查
node scripts/fetch-reference-audio.mjs
npm run check
npm test

# 完整项目验收（在真实桌面会话运行，测试应用与数据均隔离）
npm run verify:project

# Windows x64：在 Windows 或 GitHub Actions 中执行
npm run test:windows
npm run package:win
npm run verify:windows

# Apple Silicon macOS
npm run test:desktop
npm run test:app
npm run test:startup
npm run test:position
npm run test:follow
npm run test:bubble
npm run test:eyes
npm run test:blink
npm run test:expression
npm run test:menu
npm run test:performance
npm run test:sad
npm run test:characters
npm run test:accounts
npm run package:mac
npm run verify:package
```

声音测试使用隔离目录中的原声音效；首次运行测试前需准备上述音效缓存。构建输出位于 `output/`，测试报告位于 `.artifacts/`，两者均不进入源码仓库。Windows Actions 验证原生窗口、统计和解压后的独立应用，并保留构建产物。

`verify:project` 串行检查语法、单元测试和当前系统的桌面功能，覆盖窗口跟随、启动、位置恢复、声音、气泡、视线、眨眼、开心、伤心、菜单和账号测智。性能回归检查重复推送不重建未变化的卡片、图表和托盘菜单，以及常驻气泡和账号运行状态的及时更新。汇总报告与各项日志位于 `.artifacts/project-audit/`，任意检查失败会返回非零退出码。
