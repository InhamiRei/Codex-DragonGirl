# 发行验证

## Windows x64

GitHub Actions 在 Windows Server 2022 x64 的桌面会话中检查以下内容，发行目标为 Windows 10 / 11 x64：

- 编译 .NET Framework 原生桥，检查全部 JavaScript 模块。
- 编译无控制台启动助手；隔离宿主测试覆盖等待、去重、主动退出暂停、多实例恢复和更新交接。
- 仅在一次性 Windows CI 用户下实际注册、读回和移除本产品的登录项，核对中文与空格路径；不会启动该登录项，也不修改开发者本机的登录项。
- 验证统计、账户请求边界、隐私字段过滤、交互和文件资源白名单。
- 启动真实 Win32 测试窗口，检查自定义目录、网络白名单、最小化隐藏和聚焦恢复。
- 启动 Electron，检查目录发现、统计进程、托盘、透明角色、气泡和设置保存；在空用户目录中解码九段内置原声，并实点角色验证按下与松开音效。
- 构建便携 ZIP，再解压至包含中文和空格的临时路径。
- 核对源码、原生桥、x64 PE 结构与 SHA-256，脱离工程目录启动成品并重复桌面检查。
- 检查自动启动不弹管理窗口、无目标窗口不闪现、重复自动启动不抢焦点、全部宿主退出后保存结束。
- 气泡检查覆盖 100%、125%、150%、200% 显示比例和三组字体配置：双额度与今日用量完整展示、原生滚动条不占宽、长消息仍可滚动；保留截图作为视觉证据。

云端使用隔离目录，不读取真实账户。Windows 10 / 11 的显示器组合、企业策略、WSL 和真实账户网络环境仍需在对应电脑上验证，不能以测试窗口等同替代。

## macOS arm64

表情回归还会模拟原生窗口已经显示、渲染层仍保留隐藏布局的情况，确认真实轻点能同步可见性并播放星光，避免只在测试启动器中正常。

`npm run test:sad` 检查正式表情通道、两眼泪光的独立变化、泪珠向下移动、无口区域、小尺寸与翻转，以及低头不改写窗口位置。生命周期检查覆盖成功与失败表情相互替换、独立开关、减少动态效果、隐藏、自定义图片和眨眼恢复。主任务失败的监控器链路由应用集成测试覆盖，取消和子任务由单元测试区分。截图及报告保存在 `.artifacts/sad-*.png` 和 `.artifacts/sad-report.json`，可用 `DRAGONGIRL_TEST_EXECUTABLE` 验收安装包。

Apple Silicon 本地检查覆盖拖动、取消手势、透明命中、边缘吸附、多实例统计、设置、声音和气泡布局。完整集成测试使用五个隔离目录，验证多于两个实例时的统计与界面行为。

`npm run test:eyes` 使用隔离配置验证窗口外的系统鼠标坐标，分别检查虹膜、眼眶和睫毛的四向像素位移，以及身体轻微倾斜、平移和窗口锚点保持；覆盖平滑收敛停止、翻转与缩放对齐、身体单独关闭、系统减少动态效果、自定义图片和原生窗口隐藏恢复。透明命中测试同时覆盖身体位移与点击压缩、翻转的组合。截图与报告保存在 `.artifacts/eyes-*.png` 和 `.artifacts/eyes-report.json`；应用集成测试另外验证设置控件保存到磁盘并同步给角色。设置 `DRAGONGIRL_TEST_EXECUTABLE` 可直接验收打包后的应用。

`npm run test:blink` 验证睁眼、半闭眼与闭眼的实际像素、睫毛厚度、重新睁开后恢复原画，以及 60% 大小和翻转画面；同时检查鼠标静止、关闭跟随时仍能自动眨眼，连续布局不推迟计时，按压、隐藏、减少动态效果及独立开关能暂停或恢复。截图与报告保存在 `.artifacts/blink-*.png` 和 `.artifacts/blink-report.json`，同样支持通过 `DRAGONGIRL_TEST_EXECUTABLE` 验收安装包。

`npm run test:expression` 使用真实轻点、拖动与取消手势检查开心触发。在表情强度保持不变的两个时刻对比虹膜像素与亮度重心，确认光实际移动；60% 大小时再次轻点，测量每只眼睛新增白色核心的屏幕尺寸、面积与凹角轮廓，避免只检测到颜色变化就误判星芒可见。同时验证光不越过虹膜、没有嘴部图层、轻弹、两秒恢复、缩放翻转、独立开关和眨眼恢复。单元测试区分真正完成、取消、错误和子任务；应用集成测试覆盖监控器到角色的完成事件链路与开关持久化。截图与报告保存在 `.artifacts/happy-*.png` 和 `.artifacts/expression-report.json`；设置 `DRAGONGIRL_CAPTURE_EXPRESSION=1` 可用本机 FFmpeg 录制真实程序动画为 `.artifacts/happy-sparkles.mp4`，并支持 `DRAGONGIRL_TEST_EXECUTABLE` 直接验收安装包。

窗口回归测试会在隔离应用中打开真实 macOS 文件夹选择框，验证面板出现、关闭、主窗口移动及最小化后的跟随结果。Electron 集成检查同时验证角色与气泡隐藏、鼠标释放、拖拽取消、原位置恢复和用户主动隐藏状态。模态识别优先使用已有的辅助功能权限；没有权限时使用同进程窗口的居中或顶部附着关系兜底，不额外弹出授权请求。

发行验证检查 ZIP / DMG 的 SHA-256、应用源码一致性、深度签名及 DMG 完整性，挂载检查 Applications 入口，并从临时解压目录启动应用完成集成测试。

原生启动助手通过与真实主程序控制器通信验证生命期，真实桌面测试窗口用于验证宿主识别。`node scripts/startup-service-smoke.mjs` 使用唯一临时 LaunchAgent 验证系统装载、唤起与退出，结束后移除测试服务；不会更改正式登录项。`npm run test:startup` 验证真实 Electron 窗口的静默启动与退出。Windows 系统登录项仍需在实际 Windows 用户会话中验收，跨平台编译和逻辑测试不能替代该检查。

macOS 包使用 ad-hoc 签名，未进行 Apple Developer ID 公证。显示器拔插、Spaces 的全部切换组合和真实睡眠恢复需结合实际硬件验证。

## 数据与统计

位置恢复使用 `npm run test:position` 检查：先打开设置再拖动、保存偏好、重新启动、拖动后立即退出，逐项核对磁盘锚点与实际窗口位置；同时确认重启后九段内置音效无需下载。并发测试还覆盖多个角色与旧草稿同时保存，以及退出期间不重新创建后台定时器。

手动刷新等待账户请求和账本增量更新后完成。真实零值、失败、未知和过期读数分别显示；日志回退仅接受新鲜且归属匹配的快照。

发行包只包含运行时、程序、角色、九段原声音频与来源说明和文档，不携带账户、会话、数据库或本机配置。新用户无需手动下载音效；校验覆盖随包副本与原始文件逐字节一致，以及无本机副本时直接读取内置音频。
