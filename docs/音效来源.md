# 原声音效库

GPT龙娘使用 DeepSeek Balance Whale Widget 中的两组点击音效与五段事件提示音，共九个文件。

| 原文件 | 界面名称 | 分组 |
| --- | --- | --- |
| Ya1.mp3 | 小黄鸭·按下 | 小黄鸭 |
| Ya2.mp3 | 小黄鸭·松开 | 小黄鸭 |
| D1.mp3 | 音效一·按下 | 音效一 |
| D2.mp3 | 音效一·松开 | 音效一 |
| minecraft-exp-orb.wav | 经验球 | 提示音 |
| task-end-a.wav | 任务结束音一 | 提示音 |
| cost-default.wav | 消耗提示 | 提示音 |
| ask-default.wav | 提问提示 | 提示音 |
| approve-default.wav | 授权提示 | 提示音 |

来源：[DeepSeek Balance Whale Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget)，固定提交为 `5247dd6813d6e4430728f39ccc63d43cda046022`。原始地址、字节数和 SHA-256 均列于 `src/shared/audio-library.js`。

原项目的[素材说明](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget/blob/5247dd6813d6e4430728f39ccc63d43cda046022/PROVENANCE.md)区分音频素材与代码许可，`assets/` 中的音频不适用该项目的 MIT 代码许可，且未授予再许可。龙娘随应用附带这九段原声，保留来源说明，不将其标为原创，也不另行授予素材许可；素材权利与适用范围仍以原项目说明和各素材原权利人为准。

九个原文件以清单中的固定文件名保存在 `assets/audio/`，与 Windows / macOS 应用一同打包，首次启动即可离线播放，无需用户下载。`assets/audio/original-audio-sources.json` 同时记录固定提交、原始地址与摘要。构建前逐一检查文件长度和 SHA-256，缺失或损坏时停止构建。

播放与状态检查优先使用旧版本机已安装且通过校验的副本；本机副本缺失或损坏时，直接使用内置原声。「偏好设置 → 声音」中的「修复原声音效」优先从内置文件恢复到用户目录，只有两份副本均不可用时才从固定来源下载，全部校验后才替换文件。修复完成后立即恢复播放，失败不使用其他音色替代。

| 系统 | 本机音效目录 |
| --- | --- |
| Windows | `%APPDATA%\Codex DragonGirl\assets\` |
| macOS | `~/Library/Application Support/Codex DragonGirl/assets/` |

播放保留原速与完整录音，只调整所选音量。快速点击时松开音在按下音结束前四十毫秒衔接；长按在松手时播放松开音，拖动取消不补播。

开发与离线验证可执行 `node scripts/fetch-reference-audio.mjs` 下载固定测试缓存，再用 `node scripts/install-reference-audio.mjs <音效目录绝对路径>` 安装。这两条命令只处理上述九个文件；维护内置副本时，安装目录使用项目的 `assets/audio/` 绝对路径。
