## 更新内容

- **随 Codex 自动启动**：在「偏好设置 → 外观 → 启动方式」选择「随 Codex 启动」并保存一次。以后照常打开 Codex，龙娘会自动出现，自动启动不弹管理窗口。也可选择手动启动或登录电脑时启动。
- **完善启动与退出**：原生后台助手随安装包附带，无需额外安装 Node.js。跟随模式下，全部 Codex / ChatGPT 宿主退出后，自动启动的龙娘正常保存并退出；主动退出龙娘会暂停本批实例的联动，避免反复重开。支持多实例去重、安装位置更新与失败恢复。
- **修复位置记忆**：保存偏好不再用旧草稿覆盖刚拖动的新位置；多个角色更新时分别保留锚点，拖动后立即退出也会等待写入完成。
- **修复气泡滚动条**：双额度标签改为紧凑排版，完整展示额度和今日用量；隐藏原生滚动条，长消息仍可用滚轮查看，保持原有椭圆大小。
- **继续内置原声音效**：九段默认原声直接随包提供，首次打开和重启后均可离线使用，无需反复下载。

手动启动、手动打开管理界面或使用独立桌面模式时，可以继续使用账本与桌面陪伴，退出由用户控制。旧版启动偏好会保留，升级不会自动替用户开启新的联动方式。

## 下载

| 系统 | Assets 中的文件 |
| --- | --- |
| Windows 10 / 11 x64 | `Codex-DragonGirl-1.3.0-Windows-x64.zip` |
| Apple Silicon，macOS 15+ | `Codex-DragonGirl-1.3.0-macOS-arm64.dmg` |
| Apple Silicon，macOS 15+，ZIP | `Codex-DragonGirl-1.3.0-macOS-arm64.zip` |

Windows：完整解压后打开 `DragonGirl.exe`，保留旁边的运行时文件。macOS：将「Codex 龙娘.app」拖入 Applications。

升级：退出旧版，替换应用文件后手动打开新版一次。保留原用户数据目录即可继续使用设置、账本、角色与测试记录；新版会更新自动启动入口。卸载前可将启动方式切回手动启动并保存。

安装包未作商业代码签名；macOS 包采用 ad-hoc 签名，尚未进行 Developer ID 公证。可用 `SHA256SUMS.txt` 核对下载内容，构建与验证信息见 `RELEASE-INFO.json`。第三方音效的来源和适用范围见[音效来源](https://github.com/InhamiRei/Codex-DragonGirl/blob/v1.3.0/docs/音效来源.md)。
