## 更新内容

- **视线联动**：默认角色的眼睛、眼眶和睫毛跟随全屏鼠标，身体稍慢地轻微配合，缩放和翻转后仍保持对齐。
- **自然眨眼**：静止时也会不定时轻眨双眼，快速闭合后自然睁开。
- **开心星光**：轻点龙娘或主任务成功完成时，眼内星芒流动、明暗变化，约两秒后恢复。
- **伤心含泪**：主任务失败时，眼皮轻垂、泪光流动，一小滴泪珠缓缓滑落，约六秒后恢复。取消任务和子任务失败不会触发表情。
- **保持无口造型**：所有表情都通过眼神呈现；静音仍可显示，可在「偏好设置 → 外观」分别关闭跟随、眨眼和动态表情。自定义图片保持原样。
- **修复本地点击不播放表情**：同步原生窗口与渲染层的真实可见性，避免窗口已经显示却仍被当作隐藏。隐藏、拖动、系统减少动态效果时暂停，恢复后不重放旧事件。
