## 下载

| 系统 | Assets 中的文件 |
| --- | --- |
| Windows 10 / 11 x64 | `Codex-DragonGirl-1.2.0-Windows-x64.zip` |
| Apple Silicon，macOS 15+ | `Codex-DragonGirl-1.2.0-macOS-arm64.dmg` |
| Apple Silicon，macOS 15+，ZIP | `Codex-DragonGirl-1.2.0-macOS-arm64.zip` |

Windows：完整解压后打开 `DragonGirl.exe`，保留旁边的运行时文件。macOS：将「Codex 龙娘.app」拖入 Applications。

升级：退出旧版，下载对应系统的新包，替换应用文件后重启。设置和账本保存在独立用户目录中，保留目录即可继续使用。
