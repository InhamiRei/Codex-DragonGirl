## 更新内容

- **修复新安装点击无声**：九段原声音效直接随 Windows / macOS 安装包附带，首次启动即可离线播放，无需进入设置下载。
- **修复音效状态**：声音设置会同时检查内置与本机原声，新电脑不再因用户目录为空而显示「0 / 9」；旧版本机音频损坏时自动使用内置副本。
- **完善修复流程**：优先从安装包离线恢复音效，完成后立即恢复播放；只有内置与本机副本均不可用时才需要联网。
- **加强发行验证**：构建前逐一核验九段原声，桌面验收覆盖空用户目录下的音频解码、点击播放和修复后恢复。

## 下载

| 系统 | Assets 中的文件 |
| --- | --- |
| Windows 10 / 11 x64 | `Codex-DragonGirl-1.2.1-Windows-x64.zip` |
| Apple Silicon，macOS 15+ | `Codex-DragonGirl-1.2.1-macOS-arm64.dmg` |
| Apple Silicon，macOS 15+，ZIP | `Codex-DragonGirl-1.2.1-macOS-arm64.zip` |

Windows：完整解压后打开 `DragonGirl.exe`，保留旁边的运行时文件。macOS：将「Codex 龙娘.app」拖入 Applications。

升级：退出旧版，再下载对应系统的 1.2.1 新包并替换应用文件。保留原用户数据目录即可保留设置和账本，新版无需手动下载音效。

安装包未作商业代码签名；macOS 包采用 ad-hoc 签名，尚未进行 Developer ID 公证。可用 `SHA256SUMS.txt` 核对下载内容。第三方原声音效的来源和适用范围见[音效来源](https://github.com/InhamiRei/Codex-DragonGirl/blob/v1.2.1/docs/音效来源.md)。
