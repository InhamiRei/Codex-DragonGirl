## 更新内容

- **新增账号测智**：从账户总览选择账号，用鹈鹕动画或自定义提示词对比回答。先选账号，再选择共同可用的模型和思考强度；默认 GPT-6 Astra、中等思考强度、并发 1，支持 1–3 路并发和停止队列。
- **完善结果展示**：新建、记录和详情独立展示，结果卡片固定等高。HTML 完整缩放，支持预览与源码切换；生成中显示加载动画，失败或取消直接显示在预览区域，耗时与 Tokens 保持单行。
- **新增本地测试记录**：每页十条记录，展示各账号的预览缩略图、耗时和用量；支持查看、删除与导出，详情中的提示词直接展开。
- **调整账号与品牌样式**：测试账号的套餐标签紧跟账号名称，结果卡片的套餐标签靠右；统一表单与操作按钮样式，更新左上角图标和页脚。
- **修复文件选择框遮挡**：macOS 打开文件或文件夹选择框时，龙娘和气泡会暂时隐藏；关闭后恢复原位置，并保留用户主动隐藏的状态。
- **保留内置原声**：九段原声音效继续随安装包附带，首次打开即可离线播放。

账号测智会消耗所选账号的实际额度，使用独立会话和临时工作目录；结果供人工比较，不自动判定账号是否“降智”。测试记录保存在本机，升级保留原有记录。

## 下载

| 系统 | Assets 中的文件 |
| --- | --- |
| Windows 10 / 11 x64 | `Codex-DragonGirl-1.2.2-Windows-x64.zip` |
| Apple Silicon，macOS 15+ | `Codex-DragonGirl-1.2.2-macOS-arm64.dmg` |
| Apple Silicon，macOS 15+，ZIP | `Codex-DragonGirl-1.2.2-macOS-arm64.zip` |

Windows：完整解压后打开 `DragonGirl.exe`，保留旁边的运行时文件。macOS：将「Codex 龙娘.app」拖入 Applications。

升级：退出旧版，再下载对应系统的 1.2.2 新包并替换应用文件。保留原用户数据目录即可保留设置、账本和测试记录。

安装包未作商业代码签名；macOS 包采用 ad-hoc 签名，尚未进行 Developer ID 公证。可用 `SHA256SUMS.txt` 核对下载内容。第三方原声音效的来源和适用范围见[音效来源](https://github.com/InhamiRei/Codex-DragonGirl/blob/v1.2.2/docs/音效来源.md)。
