## 更新内容

- **菜单与表情预览**：右键角色或打开托盘菜单，可播放开心、伤心表情，结束后自动恢复。修复 macOS 小型透明窗口中的菜单折叠与二级项输入问题。
- **后台性能**：未变化的账户卡片、指标、图表和托盘菜单直接复用；空闲扫描复用统计汇总，减少重复数据库编译和历史状态通信。
- **信息及时更新**：常驻气泡跟随最新额度，账号测智列表及时显示运行和过期状态；额度变化时保留悬浮提示与键盘焦点。
- **启动与退出**：重新同步启动期间变化的工作区，保持精确贴边；统计进程异常及时结束等待，退出时中断读取并回收资源。
- **数据可靠性**：保留协议中的跨块中文，日志轮转或归档不再阻断其他有效读数；异常模型名和无效价格日期得到正确处理。
- **视觉效果保留**：沿用原画、原声音效、视线跟随、自然眨眼、开心星光和伤心含泪，覆盖小尺寸与翻转回归。

## 下载

| 系统 | Assets 中的文件 |
| --- | --- |
| Windows 10 / 11 x64 | `Codex-DragonGirl-1.4.1-Windows-x64.zip` |
| Apple Silicon，macOS 15+ | `Codex-DragonGirl-1.4.1-macOS-arm64.dmg` |
| Apple Silicon，macOS 15+，ZIP | `Codex-DragonGirl-1.4.1-macOS-arm64.zip` |

Windows：完整解压后打开 `DragonGirl.exe`，保留旁边的运行时文件。macOS：将「Codex 龙娘.app」拖入 Applications。

升级：退出旧版，替换应用文件后手动打开新版一次。保留用户数据目录即可继续使用原来的设置、位置、账本和测试记录。

安装包未作商业代码签名；macOS 采用 ad-hoc 签名，尚未进行 Developer ID 公证。附件 `SHA256SUMS.txt` 用于核对文件，`RELEASE-INFO.json` 记录构建提交与验证结果。
